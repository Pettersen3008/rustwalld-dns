# Community conduct

Treat contributors and users respectfully. Technical disagreement is welcome;
personal attacks, harassment, discrimination, threats and unsolicited promotion
are not. Explain concerns with concrete evidence and give others room to learn.

Respect privacy. Do not publish another person's identifying information,
credentials or network activity. Keep security reports in the private channel
described in [SECURITY.md](SECURITY.md).

These expectations apply to this project's issues, pull requests and other
project spaces. The maintainer, [@Pettersen3008](https://github.com/Pettersen3008),
may edit or remove inappropriate content, close a conversation, or restrict
participation. Use GitHub's reporting tools for abusive content; avoid reposting
private material or escalating harassment in public threads.
