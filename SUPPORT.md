# Support and feedback

Rustwall is a public alpha for Linux homelab testing. Start with the
[README](README.md), [alpha scope](docs/product/scope.md) and
[installation and recovery guide](docs/operations/install.md).

For questions, installation problems, feature requests and usability feedback,
open a [GitHub issue](https://github.com/Pettersen3008/rustwalld-dns/issues/new).
Check existing issues first. Include:

- The release tag or Git revision, operating system and relevant hardware.
- What you were trying to do, what you expected and what happened.
- Minimal reproduction steps and sanitized errors or screenshots.
- For DNS failures, a reproduction using invented domains and a local mock.

Never attach management tokens, private keys, real query histories, client
inventories or database backups. Describe your network with example addresses.
Report suspected vulnerabilities through the private channel in
[SECURITY.md](SECURITY.md), rather than public issues.

Feedback on installation, router setup, finding why a query was blocked,
temporary exceptions and backup/restore is especially useful. Include where the
interface or documentation became unclear. Support is best-effort; no response
time or availability guarantee is offered during the alpha.
